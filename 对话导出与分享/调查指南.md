# 对话导出与分享调查指南

本指南用于调查会话与消息如何被抽取、加工为可交付内容，并通过文件、剪贴板或共享服务交给其他人或其他系统。通用写作、元数据、深度和证据要求见 [`../AGENTS.md`](../AGENTS.md)。

本类目关注“从聊天记录中取出什么、如何形成分享稿、最终交付给谁”。会话事实源、schema 迁移和整库备份属于 [`../会话与消息管理/调查指南.md`](../会话与消息管理/调查指南.md)；导出按钮、弹窗和操作反馈属于 [`../Chat UI/调查指南.md`](<../Chat UI/调查指南.md>)；聊天现场的内容渲染属于 [`../消息渲染器/调查指南.md`](../消息渲染器/调查指南.md)；具有独立身份和持续生命周期的 Artifact、文档或生成式对象属于 [`../生成式输出与运行时/调查指南.md`](../生成式输出与运行时/调查指南.md)。

## 类目定义

**对话导出与分享**研究以下三段主链：

```text
会话、消息、分支或选区
  -> 内容抽取（范围、顺序、字段、附件与隐私）
  -> 分享稿生产（转换、编辑、编排、预览、生成与版本）
  -> 交付传播（文件、图片、剪贴板、链接、平台与数据集）
  -> 访问、撤销、过期、恢复或再次导入
```

满足下列任一条件的能力应纳入本类目：

- 把单条消息、消息范围、活动分支、完整会话树或批量会话导出为面向阅读、传播或交换的内容；
- 为对话生成 Markdown、文本、JSON/JSONL、HTML、PDF、PNG/JPEG 等交付物；
- 在导出前提供独立的选区、内容开关、视觉编排、实时预览、版本生成或比较工作台；
- 创建可由他人访问的会话快照、公开页面、受控链接、Gist 或其他远端发布对象；
- 为训练、评估或研究生产可移植的会话轨迹，并明确导出格式和发布边界。

以下内容默认不纳入：

- 数据库 schema 升级、整库备份恢复、应用设置同步和内部缓存迁移；
- 单纯下载消息中原有的图片或附件，以及模型图片生成；
- 操作系统、网页、视频、桌面挂件或任意窗口截图，除非截图对象明确是对话内容或由对话内容形成的分享稿；
- 普通复制一小段文本，除非项目围绕选区、格式、引用或传播建立了独立工作流；
- Artifact、文档、笔记或媒体对象自身的导出。若它们没有抽取对话内容，只在生成式输出与运行时或对应产品类目记录。

## 统一术语

| 术语 | 含义 |
|---|---|
| 导出源 | 被抽取的消息、选区、活动路径、完整树、会话集合或轨迹文件 |
| 内容口径 | 原始存储数据、可见正文、渲染结果、请求 Payload 或经过脱敏/转换的派生内容 |
| 分享稿 | 从对话内容派生、可在交付前独立预览或编辑的临时表达对象 |
| 交付物 | 最终生成的文件、图片、剪贴板内容、远端快照或公开页面 |
| 快照分享 | 分享创建时复制内容，源会话后续变化不会自动反映 |
| 实时分享 | 访问者持续看到源对象更新，或分享对象可显式同步更新 |
| 往返 | 导出结果能够重新导入并恢复项目可理解的会话、消息或分支语义 |
| 版本历史 | 同一分享稿多次生成的结果集合；需区分运行时生成历史、持久化版本和源会话分支 |

“导出”“分享”“截图”不能按按钮名称判断。下载 JSON 可能是迁移备份，也可能是面向研究的数据交付；“分享”可能只是系统 Share Sheet，也可能创建长期远端对象；“截图”可能抓取当前窗口，也可能用独立渲染器重建完整对话。调查时应按导出源、分享稿和交付物拆解。

## 必查问题

1. **入口与目标**：能力从单条消息、会话菜单、批量管理、命令、CLI 还是外部 API 进入？目标是个人存档、人际传播、跨应用交换、迁移、研究还是公开发布？
2. **导出源与粒度**：支持单消息、连续范围、任意选区、当前问答组、从开头到当前消息、活动分支、隐藏分支、完整树、整会话还是批量会话？顺序如何确定？
3. **内容口径**：导出的是持久化原始数据、当前可见内容、渲染后的 DOM、上下文管道处理结果还是实际请求 Payload？system、reasoning、工具调用、错误、引用、变量快照和隐藏内容如何处理？
4. **附件与外部资源**：图片、文件、音频、引用、远端 URL 和本地路径是内联、复制、打包、保留引用、转换还是丢弃？交付物能否离线打开？
5. **格式与可移植性**：支持哪些文本、结构化、网页、文档和图片格式？格式是否有版本、schema 或元数据？能否往返导入，未知字段和分支关系如何处理？
6. **分享稿生产**：是否存在区别于聊天现场的独立渲染器或编辑表面？能否调整内容、选区、顺序、布局、主题、尺寸、分页、水印、品牌和元信息？预览与最终产物是否使用同一管线？
7. **生成历史与版本**：重新生成是覆盖还是追加？旧版本能否查看、比较、复制、删除或恢复？配置变化如何标记旧结果？历史保存在组件内存、会话、文件还是服务端？关闭后是否保留？
8. **富内容保真**：Markdown、代码高亮、数学、Mermaid、表格、引用、工具卡、reasoning、Artifact、图片和自定义节点在导出端如何表示？不支持的内容如何降级？
9. **图片与文档生成**：是直接截取当前视口、滚动分段拼接、离屏复刻完整列表、重新排版 DOM，还是先生成中间文档再转图片/PDF？尺寸、DPR、Canvas 上限、分页、长内容和内存如何处理？
10. **分享对象与访问语义**：分享创建文件、系统分享项、Gist、站内快照、公开页面还是第三方对象？URL 是否可猜测，是否需要登录，能否克隆、更新、撤销、删除、过期或限制下载？
11. **隐私与安全**：分享前是否提示或过滤 system prompt、reasoning、工具输出、文件路径、密钥、个人信息和附件？HTML/PDF/图片生成如何处理脚本、URL、文件名、跨域资源和不可信富文本？
12. **可靠性与验证**：取消、失败、重试和临时文件如何收口？长会话、大图、离线资源、跨平台剪贴板、打印分页、分享撤销和导入往返是否有测试或运行证据？

## 能力分型

以下分型用于比较实现路线，不表示成熟度高低：

| 类型 | 典型链路 | 判定重点 |
|---|---|---|
| `E1 数据交换` | 消息/会话 -> JSON、JSONL、Markdown、文本 | 内容口径、schema、分支保留和往返能力 |
| `E2 阅读交付` | 对话 -> HTML、PDF、打印文档 | 富内容保真、资源封装、分页、离线性和安全 |
| `E3 图片分享` | 对话 -> 重排或截图 -> PNG/JPEG | 选区、独立渲染、长图策略、清晰度、水印和剪贴板 |
| `E4 链接分享` | 对话 -> 远端快照或页面 -> URL | 快照/实时、访问控制、更新、撤销、克隆和保留期 |
| `E5 发布与研究` | 会话轨迹 -> 数据集、Gist、评估或协作系统 | 脱敏、许可、外部依赖、数据谱系和消费闭环 |

一个项目可以同时属于多种类型。例如 NextChat 同时提供图片导出与链接分享；Pi 同时提供 HTML/JSONL 导出、Gist 分享和面向研究的数据发布交接。

## 与相邻类目的边界

| 相邻类目 | 本类目记录 | 留在相邻类目的内容 |
|---|---|---|
| 会话与消息管理 | 从哪些持久化对象抽取、导出是否保留身份/分支、分享快照与源会话的关系 | schema 迁移、数据库升级、整库备份恢复、会话 CRUD 和持久化事实源 |
| Chat UI | 分享稿的选择、编辑、预览、版本和交付工作流 | 按钮位置、菜单可用性、弹窗开关、Toast、焦点与响应式体验 |
| 消息渲染器 | 导出端如何复用或转换消息内容，以及导出 sink 的降级和安全契约 | 聊天现场的列表、消息壳、Markdown、工具卡和流式渲染 |
| 生成式输出与运行时 | 对话内容被抽取并形成分享稿或交付物的部分 | Artifact、文档、画布、媒体等独立输出对象自身的编辑、运行、版本和导出 |
| 独特功能 | 普通导出与分享不重复记独特贡献；研究发布或完整社会化工作流只回链本类 | 横跨多个类目且形成产品辨识度的发布、协作或研究闭环 |
| Agent 角色 | 对话导出是否携带角色快照、头像、名称或提示词 | 角色实体自身的导入导出、资产打包和版本管理 |

同一能力可以在不同类目各记录一次，但本类目必须回答交付语义。例如“导出图片”在 Chat UI 只记录入口和反馈；本类目则记录消息范围、独立渲染、尺寸策略、版本历史、PNG 生成和复制/保存结果。

## 推荐结构

```md
## 结论摘要
## 系统边界与完整主链
## 1. 入口、用户目标与导出源
## 2. 范围选择、内容口径与字段过滤
## 3. 附件、资源与离线封装
## 4. 格式、schema 与往返能力
## 5. 分享稿编辑、编排与预览
## 6. 图片、HTML、PDF 与富内容生成
## 7. 生成历史、版本与持久化
## 8. 分享载体、访问控制与撤销
## 9. 隐私、安全与内容治理
## 10. 性能、失败恢复与测试
## 11. 设计取舍与已确认边界
## 12. 未验证事项
## 13. 关键源码索引
```

项目没有分享稿编辑器或远端分享时，明确写“不适用”或“本次未找到”，不为形式完整而虚构对应对象。

## 调查方法

- 先列出所有入口和输出格式，再逐一追踪它们是否共享同一抽取、转换和交付管线；同名“导出”可能对应完全不同的数据口径。
- 图片能力必须确认捕获对象。依赖 `html2canvas`、`html-to-image` 或 `modern-screenshot` 只能生成候选，不能证明它用于对话分享。
- 公开链接必须继续追踪服务端对象、token、权限、刷新与删除路径；复制 URL 本身不等于分享治理已经闭环。
- 声称“保留完整会话”时，检查隐藏分支、system、工具调用、reasoning、附件和外部引用；只看到可见消息不应写成完整导出。
- 区分预览 DOM、生成结果和持久化版本。截图缩略图列表可能只是组件内存状态，不能据此声称跨会话版本历史。
- 静态代码可以确认调用链、字段和权限判断；图片保真、打印分页、剪贴板兼容、长内容性能和链接实际可访问性需要运行验证。

## 横向比较字段

至少记录：用户目标、导出粒度、内容口径、隐藏分支、敏感内容策略、附件策略、格式、离线性、往返能力、分享稿编辑、预览方式、生成版本、图片/文档生成路线、富内容保真、分享载体、快照或实时、访问控制、更新与撤销、保留期、外部依赖、失败恢复和验证强度。
