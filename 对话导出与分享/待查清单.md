# 对话导出与分享待查清单

本清单用于建立新类目的首批调查顺序，不替代单项目调查笔记或横向对比。状态仅表示当前定位深度；正式结论需按 [`调查指南.md`](调查指南.md) 走通“内容抽取 -> 分享稿生产 -> 交付传播”主链。

## 第二批通用导出样本

| 项目 | 当前候选 | 首轮重点 |
|---|---|---|
| Chatbox | `E1`、`E2` | HTML/Markdown/JSON 等格式范围、reasoning 与工具结果口径、HTML 文件名/标题转义、资源封装与备份导出的边界 |
| SillyTavern | `E1` | JSONL 原样与文本导出、角色/群聊格式转换、附件与 swipe/branch 保留、跨格式导入往返 |
| AIO Hub 之外的角色生态 | `E1` | 会话与角色卡/世界书/预设导入导出需分开记录，避免把角色资产交换误算为对话导出 |
| Manifold Desktop | `E1` | Markdown 导出已接 UI，JSON handler 未找到调用；确认输出范围、编码、格式和入口完整性 |
| LobeHub | `E1`、可能的 `E4` | Topic import/duplicate 与真正对外交付的边界；服务端复制对消息、附件和分支的语义 |
| Hermes Agent | `E1` | `session.save` JSON 是否只是本地快照；system prompt、工具和附件口径；是否存在导入、链接分享或研究轨迹交接 |

## 相邻候选与排除项

| 项目 | 当前判断 | 需要确认的边界 |
|---|---|---|
| VCPChat | 相邻候选 | Text Viewer 支持正文编辑后“截图分享”，但当前确认的是阅读器内容，不是直接从对话选择消息；需追踪聊天消息进入阅读器的入口和源内容关系 |
| DeepChat Artifact | 排除到生成式输出与运行时 | Artifact 复制为图片属于独立输出对象导出，不与对话截图重复计 |
| Open WebUI Notes | 排除到 Notes/独特功能 | Notes 转 PDF 不以对话为导出源 |
| VCPChat 桌面挂件截图 | 排除到生成式输出与运行时 | 截取的是桌面活对象，不是对话分享稿 |
| 模型图片生成与消息原图下载 | 排除 | 没有把对话内容转换为新的分享交付物 |

## 低信息或待确认项目

AstrBot、Jan、VCPToolBox 当前未找到最终用户对话图片分享主链；其普通会话导出或平台转发能力仍需按指南搜索入口后再判断。项目没有最终用户会话所有权时，可以标记本类目不适用，不创建空白笔记。

## 建议调查顺序

1. AIO Hub：先建立分享稿编辑、实时预览和运行时版本历史的完整样本。
2. NextChat、Cherry Studio、DeepChat：补齐重排生成、离屏复刻和现场滚动截图三种图片路线。
3. Open WebUI：建立 PDF 阅读交付和受控快照分享样本。
4. Pi、OpenCode：建立 Gist、远端分享和研究轨迹发布样本。
5. Chatbox、SillyTavern、Manifold Desktop：补齐格式交换和往返兼容样本。

前四个图片样本已形成[图片分享生成局部横向对比](图片分享生成局部横向对比.md)。完整类目横向对比应等待链接分享、PDF/HTML 和结构化数据交换样本均有单项目笔记后再建立。
