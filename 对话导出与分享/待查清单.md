# 对话导出与分享待查清单

本清单用于建立新类目的首批调查顺序，不替代单项目调查笔记或横向对比。状态仅表示当前定位深度；正式结论需按 [`调查指南.md`](调查指南.md) 走通“内容抽取 -> 分享稿生产 -> 交付传播”主链。

## 相邻候选与排除项

| 项目 | 当前判断 | 需要确认的边界 |
|---|---|---|
| VCPChat | 相邻候选 | Text Viewer 支持正文编辑后“截图分享”；当前仅确认阅读器内容，尚未确认直接从对话选择消息的路径，需追踪聊天消息进入阅读器的入口和源内容关系 |
| DeepChat Artifact | 排除到生成式输出与运行时 | Artifact 复制为图片属于独立输出对象导出，不与对话截图重复计 |
| Open WebUI Notes | 排除到 Notes/独特功能 | Notes 转 PDF 不以对话为导出源 |
| VCPChat 桌面挂件截图 | 排除到生成式输出与运行时 | 截取对象为桌面活对象，不属于对话分享稿 |
| 模型图片生成与消息原图下载 | 排除 | 没有把对话内容转换为新的分享交付物 |

## 低信息或待确认项目

AstrBot、Jan、VCPToolBox 当前未找到最终用户对话图片分享主链；其普通会话导出或平台转发能力仍需按指南搜索入口后再判断。项目没有最终用户会话所有权时，可以标记本类目不适用，不创建空白笔记。首轮派工（2026-08-14）未覆盖这三个项目。

## 建议调查顺序

首批 7 个项目与第二批 5 个项目的单项目笔记已齐（2026-08-14），首轮重点全部静态确认完毕，剩余以运行验证为主。后续顺序：

1. 运行验证轮：AIO Hub 极长图与 3x 输出、NextChat ShareGPT 服务端行为、Open WebUI PDF/三态鉴权、Pi Gist 往返不一致、OpenCode 分享服务端与 PR 格式不一致，均需实际运行或服务端证据才能收口。
2. 低信息或待确认项目：AstrBot、Jan、VCPToolBox 按指南搜索入口后再判断是否建笔记。
3. 横向对比：完整类目横向对比应等待链接分享、PDF/HTML 和结构化数据交换样本均覆盖后再建立；当前[图片分享生成局部横向对比](图片分享生成局部横向对比.md)需增补 Cherry Studio/DeepChat 补查后的新结论。

前四个图片样本已形成[图片分享生成局部横向对比](图片分享生成局部横向对比.md)。完整类目横向对比应等待链接分享、PDF/HTML 和结构化数据交换样本均有单项目笔记后再建立。
