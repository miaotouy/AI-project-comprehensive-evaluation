## 项目概览

VCPMobile 是 VCPChat 的 Android 优先移动端，使用 Vue 3 WebView、Tauri/Rust 与 Kotlin/Swift 双平台插件构成单一应用表面。它把本地 SQLite 中的话题与消息、远端 VCP 网关的推理/长期内容，以及手机的原生能力放到同一工作区；模型 Provider、远端工具循环、RAG 索引和日记的最终存储均不在此仓库内。语音通话、语音输入与 TTS 朗读是同一应用表面上的独立通路，录音与语音活动检测在本机完成。

聊天是唯一常驻路由。设置、同步、日记、设备节点和 RAG 观察器等低频工作区通过全局覆盖层中的虚拟页面进入，Android 返回事件按该页面栈、弹窗与抽屉逐层收回。当前快照的 Git 历史完整可达：905 次提交、时间跨度约 2026-03-03 至 2026-11-02，并有 `v0.9.0` 到 `v1.1.5` 的版本标签，可用于核对 README 的版本自述。[产品结构与设计基因调查笔记](../产品结构与设计基因/VCPMobile-产品结构与设计基因调查笔记.md)、[应用界面基础设施调查笔记](../应用界面基础设施/VCPMobile-应用界面基础设施调查笔记.md)

## 已调查能力

### 本地聊天与呈现

- **可恢复的移动端聊天**：Agent 或 Group 下的 Topic 是会话单位，Topic、线性消息、附件、全文索引、预渲染块和未终结生成均由本地 SQLite 持久化。发送会先写入用户消息，再由 Rust 组装历史和附件文本，向 VCP 网关发起 SSE；前端按帧合并增量，最终以事务写入助手消息和缓存。编辑或重新生成会截断后续线性历史，当前未找到消息树或分支版本。证据状态：`主链确认`（静态源码）。[Chat 调查笔记](../Chat/VCPMobile-Chat调查笔记.md)、[会话与消息管理调查笔记](../会话与消息管理/VCPMobile-会话与消息管理调查笔记.md)、[对话请求与上下文调查笔记](../对话请求与上下文/VCPMobile-对话请求与上下文调查笔记.md)

- **全文搜索与阅读现场**：Agent 侧栏可打开本地全局消息搜索，按 owner/Topic、发言者、角色和时间筛选；结果点击带消息 ID 经 Rust 导航仲裁进入锚点窗口。默认历史初载 5 条、上翻 10 条，最多保留 500 条；导航、通话与删除共享 Rust 准入，WebView 仅保存冷提示及权威焦点投影，固定窗口可在回复到达时保留阅读区。证据状态：`主链确认`（静态源码）。[会话与消息管理调查笔记](../会话与消息管理/VCPMobile-会话与消息管理调查笔记.md)、[Chat UI 调查笔记](<../Chat UI/VCPMobile-ChatUI调查笔记.md>)

- **消息块与附件显示**：Rust 预编译 Markdown/结构化消息块并缓存，前端以有界分页窗口、流式尾部 rAF 合并和块级组件显示文本、思考、工具、代码及附件。附件由本地受控存储、类型识别和提取文本链路支持；静态证据不能确认真实 Android WebView 的滚动、长内容和多媒体呈现。证据状态：`主链确认`（静态源码）。[消息渲染器调查笔记](../消息渲染器/VCPMobile-消息渲染器调查笔记.md)、[Chat UI 调查笔记](<../Chat UI/VCPMobile-ChatUI调查笔记.md>)

- **语音通话与朗读**：语音输入、语音通话与 TTS 朗读由双平台原生插件采集和播放，Rust 语音服务承担语音活动检测、识别请求、分段与合成，Rust 持有通话与朗读业务快照，前端独立 Store 投影麦克风、识别、回复与朗读状态，并在通话结束时回到普通 Composer。朗读与生成任务按消息 ID 对齐，可单独停止。证据状态：`主链确认`（静态源码）。[Chat UI 调查笔记](<../Chat UI/VCPMobile-ChatUI调查笔记.md>)、[消息渲染器调查笔记](../消息渲染器/VCPMobile-消息渲染器调查笔记.md)、[产品结构与设计基因调查笔记](../产品结构与设计基因/VCPMobile-产品结构与设计基因调查笔记.md)

### VCP 网关、Agent 与运行时

- **单网关模型接入**：应用保存一套 VCP URL 与 API Key，模型目录从同一网关读取并以模型 ID 缓存；每个 Agent 仅持有模型 ID 和生成参数。请求由客户端送往该网关，多 Provider 路由、成本、密钥轮换和容灾若存在，属于网关后端而非 VCPMobile。证据状态：`主链确认`（静态源码）。[LLM 渠道管理调查笔记](../LLM渠道管理/VCPMobile-LLM渠道管理调查笔记.md)、[Agent 角色配置调查笔记](../Agent角色/VCPMobile-Agent角色配置调查笔记.md)

- **本地 Agent 配置与远端设备工具**：Agent 是 SQLite 中的身份、提示词、模型和生成参数配置；手机还能作为独立分布式节点连接 VCP 服务。用户逐项启用设备能力后，节点注册工具目录，服务端可经持续 WebSocket 发送调用并接收结果。移动端不解析本地 function calling，也不持有“模型调用工具后继续生成”的循环。证据状态：`主链确认`（静态源码）。[Agent 角色配置调查笔记](../Agent角色/VCPMobile-Agent角色配置调查笔记.md)、[Agent 工具调查笔记](../Agent工具/VCPMobile-Agent工具调查笔记.md)、[外部执行体与应用协作调查笔记](../外部执行体与应用协作/VCPMobile-外部执行体与应用协作调查笔记.md)

- **Android 本地 CLI 执行节点**：启用的 `VCPMobileCLI` 将外部 ACK 身份和请求 ID 映射为稳定 session/operation，经过类型化参数校验进入本机 job 运行时，再由原生 ProcessHost 启动 PRoot shell。Skill 目录、读取和物化、输出游标、轮询、取消以及 JSON 作业账本均有实现；账本可重放结果，实际运行进程仍受 Android 生命周期约束，未确认重启后无缝续跑。证据状态：`主链确认`（静态源码）。[Agent 工具调查笔记](../Agent工具/VCPMobile-Agent工具调查笔记.md)、[外部执行体与应用协作调查笔记](../外部执行体与应用协作/VCPMobile-外部执行体与应用协作调查笔记.md)

- **生成结果与外部认知观察**：流式文本终结后可生成消息级 HTML 预览；它是嵌入式 iframe Artifact，并非可编辑、版本化的通用工作区。RAG 观察器从远端 VCPInfo 事件读取检索、记忆和思考活动并展示原始数据，本地不摄取文档、不建立向量索引，也不将观察结果注入聊天上下文。证据状态：`主链确认`（静态源码）。[生成式输出与运行时调查笔记](../生成式输出与运行时/VCPMobile-生成式输出与运行时调查笔记.md)、[检索增强与认知编排调查笔记](../检索增强与认知编排/VCPMobile-检索增强与认知编排调查笔记.md)

### 移动端工作区与差异化能力

- **分域配置备份与恢复**：连接设置页统一文件导入导出入口；数据库配置、实体专属设置、模型收藏和 Tarven 规则以版本校验及事务收口，界面偏好另回各 Store 恢复。未同步实体设置暂存后提示用户再次恢复，复刻音频样本另行处理。证据状态：`主链确认`（静态源码），整份文件跨存储恢复并非单一原子事务。[应用界面基础设施调查笔记](../应用界面基础设施/VCPMobile-应用界面基础设施调查笔记.md)

- **远端日记中心**：手机端提供远端日记文件的检索、编辑、冲突处理和创建工作区。日记内容与语义搜索服务仍由外部 VCP 侧拥有；本仓库确认的是移动端的访问、编辑和冲突处理链。证据状态：`主链确认`（静态源码）。[独特功能调查笔记](../独特功能/VCPMobile-独特功能调查笔记.md)

- **移动平台原生能力接入**：同一份 Tauri 插件在 Android（Kotlin）与 iOS（Swift）两侧实现，把权限、文件、硬件状态、前台保活、网络/设备信息、录音播放、键盘 Insets、窗口几何与生命周期桥接给应用；iOS 另有系统分享扩展。前端的覆盖页、语义化层级、通知和主题状态与系统返回事件共同构成移动端交互框架。证据状态：`主链确认`（静态源码）。[应用界面基础设施调查笔记](../应用界面基础设施/VCPMobile-应用界面基础设施调查笔记.md)、[外部执行体与应用协作调查笔记](../外部执行体与应用协作/VCPMobile-外部执行体与应用协作调查笔记.md)

## 已知边界与未覆盖事项

- 全部结论以静态源码为主，未启动 Android 或 iOS 应用、未连接 VCP 网关、VCPInfo、日记或分布式服务，也未在真机上验证权限、通知、返回手势、前台保活、语音采集与回声、SSE 或断线重连。
- VCPMobile 不是模型 Provider、远端 RAG/记忆执行器或工具循环宿主；这些系统的实现与安全边界需要到 VCP 服务端仓库复查。
- 当前未找到完整对话导出/分享工作流；这表示本轮已检索范围内没有可确认实现，不排除外部服务或未来版本提供该能力。
- 附件预处理、预览和保存不构成媒体创作工作站，故未建立媒体创作笔记。悬浮助手的入口页、主线程、状态 Store 与 Android 浮窗管理已不在快照中，其仓库文档只作历史材料。
- 日志中心、任务中心、Agent 管理、论坛、邮箱和引导浮层只在产品结构层面确认；全局消息搜索与 CLI 执行主链由对应专项承担。未检查所有 CLI Skill 内容、设备权限、进程资源限制或真实远端调用。
- iOS 构建、ONNX Runtime 头文件解析与分享扩展只在配置与源码层面确认，未执行 iOS 构建。
