## 项目概览

Risuai 是 Svelte 5 + Tauri 2.5 的角色扮演聊天应用，载体为桌面 GUI、Web 静态站、移动 Web 与 Node 服务器内嵌四种形态，单一 SPA 代码库经运行时探测服务全部平台。聊天状态全部驻留前端内存，`DBState.db` 是唯一权威对象，由常驻保存循环按角色分块增量编码到单一二进制存档 `database/database.bin`。主链集中在巨型编排函数 `sendChat`（`src/ts/process/index.svelte.ts:99`），完成上下文拼装、记忆、组装、渠道请求与流式回写。产品辨识度不在角色卡或世界书基线，而在于"模型输出与角色媒体表现接成闭环的指令标签链"（情绪图/出图/资产标签）、双层安全模型的原生插件运行时与本地优先的文件/翻译/多用户工作流。

### 渠道与调度

- **渠道模型**：Risuai 没有 Provider 实体表或渠道实例对象，Provider 只是模型条目上的分类标签（`LLMProvider` 枚举 17 值）；运行时使用模型 ID 和全局 Database 字段组合出连接参数，Endpoint 由内置模型条目、反向代理字段或自定义模型记录承载，多连接靠条目复制与自定义模型数组表达。证据状态：静态源码确认。[LLM 渠道管理调查笔记](../LLM渠道管理/Risuai-LLM渠道管理调查笔记.md) 第 1 节

- **模型目录三层来源**：静态内置表 + 启动时动态注册（Google/Anthropic/OpenAI 目录）+ 设置页实时拉取（OpenRouter/NanoGPT/Ollama/Horde），远端结果不持久化；元数据以能力位 flags 与参数白名单直接驱动请求行为（system prompt 处理、角色交替、采样参数注入）。证据状态：静态源码确认。[LLM 渠道管理调查笔记](../LLM渠道管理/Risuai-LLM渠道管理调查笔记.md) 第 4 节

- **协议 Adapter 与请求组装**：`requestChatDataMain` 按 `LLMFormat` 枚举（24 值）switch 分发到各 Adapter；OpenAI 兼容是主干，Custom API（`reverse_proxy`）可切换格式复用 Anthropic/Gemini/Responses Adapter；各 Adapter 自行拼 URL、Header、请求体与流式解析，Rust 端只做字节转发、不解析 SSE。证据状态：静态源码确认。[LLM 渠道管理调查笔记](../LLM渠道管理/Risuai-LLM渠道管理调查笔记.md) 第 5 节、[对话请求与上下文调查笔记](../对话请求与上下文/Risuai-对话请求与上下文调查笔记.md) 第 4 节

- **凭据、代理与网络边界**：凭据以明文字符串存于 `database.bin`（Tauri）或 IndexedDB（Web），无独立凭据存储、无磁盘静态加密；Web 请求经 hub/自托管 `/proxy2` 中转（凭据完整经过中转进程），Tauri 走 `streamed_fetch` 命令，局域网地址在 `localNetworkMode` 下直连；请求日志含完整 headers 与 body（API Key 可见，无脱敏）。证据状态：静态源码确认。[LLM 渠道管理调查笔记](../LLM渠道管理/Risuai-LLM渠道管理调查笔记.md) 第 3 节

- **重试与 fallback**：`requestChatData` 双层循环——同模型按 `requestRetrys`（默认 2）重试 + 按任务模式分离的模型 fallback 候选链（候选为任意模型 ID、可跨 Provider）；触发条件是错误类型与空响应，不是健康状态；无多 Key、无 Key 轮换、无熔断、无健康感知 failover。证据状态：静态源码确认。[LLM 渠道管理调查笔记](../LLM渠道管理/Risuai-LLM渠道管理调查笔记.md) 第 7 节、[对话请求与上下文调查笔记](../对话请求与上下文/Risuai-对话请求与上下文调查笔记.md) 第 4 节

- **全局单任务并发与停止**：`doingChat` 全局锁拒绝新的顶层发送，不排队、不替换当前任务；群聊成员与自动续写是带同一 AbortController 的顺序递归；停止只在本地消费层生效（`reader.cancel()`），桌面端 `streamed_fetch` 无取消命令，网络请求继续到结束或 240 秒超时。证据状态：静态源码确认。[对话请求与上下文调查笔记](../对话请求与上下文/Risuai-对话请求与上下文调查笔记.md) 第 7、8 节、[Chat UI 调查笔记](<../Chat UI/Risuai-ChatUI调查笔记.md>) 第 5 节
