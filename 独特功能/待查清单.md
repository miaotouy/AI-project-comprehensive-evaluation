# AI 客户端独特功能待查清单

> 对比对象：`AIO Hub`、`AstrBot`、`Chatbox`、`Cherry Studio`、`DeepChat`、`Hermes Agent`、`Jan`、`LobeHub`、`Manifold Desktop`、`NextChat`、`OpenCode`、`Open WebUI`、`Pi`、`Risuai`、`SillyTavern`、`VCPChat`、`VCPToolBox`
>
> 对比更新日期：2026-08-14
>
> 依据：各项目根 README、中文介绍、VCPToolBox 文档索引与功能矩阵、现有十个调查类目的单项目笔记，以及仓库当前 HEAD 与笔记代码快照核对结果
>
> 对比方法：从项目介绍提取现有通用类目未完整承接的候选能力，按介绍候选、入口确认、主链确认、运行确认、声明不符、归并已有类目和暂缓七种状态维护；本清单不把介绍声明直接当作实现事实
>
> 对比范围：项目特有或低普及度的产品工作流、跨类目组合能力和旁路产品面；排除普通 Chat 底座、纯工程指标及已被现有类目完整覆盖的常见能力
>
> 文档定位：独特功能专项的调查路由与状态清单，不作为功能存在性结论、贡献排名或整改方案

## 使用说明

- 状态定义和升级规则见[调查指南](调查指南.md)。
- “已有证据”表示现有笔记中存在可复用调查，不表示该候选已经完整闭环。
- 项目介绍过于简略时，先补产品表面盘点，不因 README 没写就判断项目没有特色。
- 每完成一项专项调查，应更新状态、结论文档和对[特色功能贡献统计](../AI客户端特色功能贡献统计.md)的影响。

## 跨项目待形成的自然聚类

这些方向已有多个候选，但在完成能力卡前不建立统一评分：

| 聚类 | 候选项目 | 需要先解决的比较问题 |
|---|---|---|
| 主动 Agent 与后台任务 | VCPChat、VCPToolBox、Hermes Agent、Open WebUI、LobeHub、AstrBot | FlowLock、cron、Calendar、Schedule、follow-up、Agent Sandbox 的触发者和结果归属不同 |
| 记忆演化与用户建模 | VCP 系、Hermes Agent、LobeHub、Open WebUI、SillyTavern | 规则注入、RAG、用户事实、语义联想、梦境整理和后台复习的计数触发不是同一对象 |
| 协同工作区 | VCPChat、LobeHub、Open WebUI、Cherry Studio、OpenCode | Canvas、Pages、Notes、文件项目和 Git 工作区的事实源不同 |
| Agent 社会与群体 | VCP 系、LobeHub、AstrBot、DeepChat、Hermes Agent | 角色群聊、任务委派、Agent Groups、论坛和 IM 机器人需要分型 |
| 人类可操作工具面 | VCPChat、Open WebUI、LobeHub、Cherry Studio | 自动 GUI、工具卡、工作流和专用面板的生成方式不同 |
| 多表面与远程连续性 | Hermes Agent、OpenCode、DeepChat、AstrBot、VCPChat、Open WebUI | 共享会话、遥控会话、跨设备同步和平台消息投影不能混为一项 |
