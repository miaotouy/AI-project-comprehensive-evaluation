# 会话与消息管理调查指南

本指南用于调查会话与消息作为可寻址、可持久化业务对象时的数据模型、生命周期和查询操作。通用写作、元数据、深度和证据要求见 [`../AGENTS.md`](../AGENTS.md)。

本类目关注“系统保存了什么、用户操作改变了什么、重新打开后如何恢复”。一次模型请求如何执行属于 [`../对话请求与上下文/调查指南.md`](../对话请求与上下文/调查指南.md)，用户如何通过界面完成这些操作属于 [`../Chat UI/调查指南.md`](<../Chat UI/调查指南.md>)。

## 调查目标

说明会话、消息、分支和索引的事实源，走通一条“创建或打开 -> 读取 -> 修改 -> 持久化 -> 查询或恢复”的完整主链。项目不拥有跨请求会话状态时，先说明边界，不为形式完整而虚构 Session 或消息数据库。

## 必查问题

1. **会话单位**：Session、Thread、Topic、Conversation、Chat 等概念分别表示什么？标识如何生成，彼此如何关联？
2. **消息模型**：消息是线性数组、树、事件日志、父子 part 还是其他结构？role、附件、reasoning、工具调用和状态字段如何表示？
3. **事实源与存储**：会话索引、消息详情、草稿、摘要和分支指针分别存在哪里？内存、缓存、文件、数据库和远端服务中谁是权威源？
4. **生命周期**：新建、惰性创建、切换、重命名、置顶、归档、删除、恢复、清理空会话和过期回收如何实现？
5. **消息操作与分支**：编辑、删除、重试、续写、回退、分支、版本切换和复制会话分别修改原对象还是创建新对象？活动路径如何确定？
6. **列表、索引与检索**：会话列表和消息查询是否分页？排序、分组、未读、全文搜索、命中定位和索引自愈如何实现？
7. **一致性与同步**：乐观更新、流式临时状态、落盘节流、多窗口、多端和并发写入如何合并？如何拒绝过期响应或避免重复消息？
8. **迁移与交换**：schema 版本、数据库迁移、用于恢复或搬迁的导入导出、备份恢复和未知字段兼容如何处理？面向阅读、传播和发布的导出与分享进入 [`../对话导出与分享/调查指南.md`](../对话导出与分享/调查指南.md)。
9. **外部对象绑定**：Agent、角色、模型、Provider、知识库、工具和附件在会话级、分支级还是消息级绑定？保存引用还是历史快照？
10. **恢复与保留语义**：异常退出、崩溃、压缩轮转、服务端重连或本地文件缺失后能够恢复什么？哪些状态明确不持久化？

## 与相邻类目的边界

| 相邻类目 | 本类目记录 | 留在相邻类目的内容 |
|---|---|---|
| 对话请求与上下文 | 请求开始前读取哪些持久化对象，结束后写回哪些对象 | 上下文拼装、Provider 调用、流式事件、取消、重试和队列执行 |
| Chat UI | 界面动作最终改变的数据对象和持久化结果 | 会话侧栏、搜索面板、分支导航、确认流程和现场恢复体验 |
| 消息渲染器 | 消息与 part 的持久化形状，以及可见列表的数据分页接口 | 列表窗口化、滚动锚定、消息壳和内容组件 |
| 对话导出与分享 | 导出从哪些持久化对象取数，以及分享快照与源会话的身份关系 | 内容选择与转换、分享稿、格式、图片/PDF 生成、链接访问和撤销 |
| Agent 角色 | 角色引用、覆盖字段和历史快照的保存方式 | 角色实体、配置、提示词字段和导入导出 |
| Agent 工具 | 工具调用与结果是否成为持久化消息或事件 | 工具发现、协议、执行循环、审批和结果处理 |
| LLM 渠道管理 | 会话保存哪个模型、渠道或 profile 引用 | 渠道实体、凭据、路由解析、重试和故障转移 |

同一能力可以在不同类目各出现一次，但本类目只回答数据语义。例如“停止生成”只记录半截 assistant 消息、任务引用和完成标记最终如何保存，不展开停止按钮或网络 abort。

## 调查注意事项

- UI 列表中出现一条会话，不等于持久化层已经创建对应对象；需要确认惰性创建和首次发送时机。
- 内存 store、查询缓存和数据库可能同时保存消息，必须指出权威源、投影和合并方向。
- “分支”可能表示消息树、assistant 版本、会话复制、checkpoint 或上下文轮转，先按实际数据变更定义。
- 静态代码可以确认事务、索引和写入入口，不能代替崩溃恢复、多窗口竞争和大数据量搜索验证。
- 声称“不支持恢复”时，写明检查过的存储入口、迁移代码和恢复路径。

## 横向比较字段

至少记录：会话单位、消息事实源、存储模型、创建时机、分支模型、写入时机、索引与分页、搜索粒度、同步方式、迁移机制、外部对象绑定粒度、异常恢复和保留语义。
